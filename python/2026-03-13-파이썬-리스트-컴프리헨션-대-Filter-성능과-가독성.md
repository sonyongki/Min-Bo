### Context
파이썬에서 리스트 데이터를 필터링할 때 리스트 컴프리헨션(List Comprehension)은 매우 강력한 도구이지만, 다중 조건부(`if condition1 if condition2`)가 포함될 경우 코드의 가독성이 급격히 저하되는 문제가 발생합니다. 특히 비전공자나 초보 개발자에게는 이러한 구문이 해석하기 어려운 장벽이 됩니다. 이를 해결하기 위해 `filter()` 함수 사용을 고려할 수 있으나, 대량 데이터 처리 시 두 방식 간의 성능 차이를 명확히 이해하고 상황에 맞는 가이드라인을 수립할 필요가 있습니다.

### Core
리스트 컴프리헨션과 `filter()` 함수를 사용한 다중 조건 필터링의 구현 방식 및 성능 측정 예시입니다.

```python
import timeit

# 샘플 데이터: 1부터 1,000,000까지의 숫자
data = range(1, 1000001)

# 1. Nested List Comprehension (다중 조건)
# 짝수이면서 5의 배수인 숫자 필터링
def use_comprehension():
    return [x for x in data if x % 2 == 0 if x % 5 == 0]

# 2. filter() 함수와 lambda 사용
def use_filter():
    return list(filter(lambda x: x % 2 == 0 and x % 5 == 0, data))

# 성능 측정 (각 10회 반복)
comp_time = timeit.timeit(use_comprehension, number=10)
filter_time = timeit.timeit(use_filter, number=10)

print(f"List Comprehension: {comp_time:.4f}s")
print(f"Filter + Lambda: {filter_time:.4f}s")
```

### Insight
리스트 컴프리헨션과 `filter()` 함수 사이의 선택은 '성능'과 '가독성'의 트레이드오프 관계를 가집니다.

*   **성능적 측면**: 리스트 컴프리헨션이 `filter()`와 `lambda` 조합보다 일반적으로 더 빠릅니다. 이는 `filter()`가 각 요소마다 파이썬 함수(람다 포함)를 호출하는 오버헤드(Function Call Overhead)를 발생시키기 때문입니다. 반면 컴프리헨션은 C 언어 수준에서 최적화된 루프로 실행됩니다.
*   **가독성 측면**: 중첩된 `if` 문이 들어간 리스트 컴프리헨션은 논리 구조를 한눈에 파악하기 어렵습니다. 비전공자나 교육용 코드에서는 명시적인 `for` 루프와 `if` 문을 사용하거나, `filter()` 함수를 사용하여 로직을 분리하는 것이 유지보수에 유리합니다.
*   **최적의 가이드라인**:
    *   데이터 크기가 작고 협업 및 가독성이 우선인 경우: `filter()` 또는 명시적인 `for` 루프를 권장합니다.
    *   실시간 대용량 데이터 처리나 연산 최적화가 필수인 경우: 리스트 컴프리헨션을 사용하되, 복잡한 조건은 `and` 연산자로 결합하거나 주석을 병기하여 보완합니다.
    *   파이썬 3 이상의 버전에서는 `filter()`가 이터레이터(Iterator)를 반환하므로, 메모리 효율성이 극도로 중요한 경우(전체 리스트를 즉시 생성할 필요가 없는 경우)에는 `filter()`가 대안이 될 수 있습니다.
